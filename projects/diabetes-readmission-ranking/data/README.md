# Data

Download the [UCI Diabetes 130-US Hospitals dataset](https://archive.ics.uci.edu/dataset/296/diabetes+130-us+hospitals+for+years+1999-2008), licensed under [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/), and place these files here:

```text
data/
├── diabetic_data.csv
└── IDS_mapping.csv
```

Raw data is intentionally excluded from Git.
